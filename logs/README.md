# Codex Design Logs

## 文档定位

本目录保存 Codex Design 自动化工具的本地运行记录，包括桌面快捷方式生成日志、环境检测日志和其他自动化工具日志。

日志用于问题排查、环境确认和工具运行追踪，不属于生产交付、客户资料或供应商说明。

## 文件管理

默认保留策略：

- 同一类自动报告保留最近 5 份。
- 正在排查的问题可以临时保留更多，问题关闭后恢复默认数量。
- `shortcut_install.log` 保留当前有效的一份；重新生成成功后可替换旧记录。
- `logs/README.md` 永久保留并纳入 Git，其余运行日志默认不进入 Git。
- 日志不得记录密码、Token、API Key、Cookie、私钥或代理凭据。

清理只针对自动生成的运行日志，不删除人工报告、生产交付或仍在排查的问题证据。
