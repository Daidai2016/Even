# AIGC 创意能力与 Skill 建设规范

## 1. 文档定位

本文档只定义 AIGC 图像生成主线的创意能力、训练方法、skill 结构和质量标准。

仓库操作与安全规则见 `AGENTS.md`；代码、工具和交付物的通用开发规范见 `CODING_RULES.md`。

## 2. 四类核心能力

### 2.1 审美训练

目标：建立稳定的视觉判断，而不是复制单一风格。

重点：

- 构图、比例、视觉重心和负空间。
- 色彩关系、光影、层次、材质和氛围。
- 风格一致性、细节完成度和品牌适配性。
- 好与不好的对比例，以及可说明的判断理由。

产出：参考集、评价维度、对比案例和可复用审美 skill。

### 2.2 版式训练

目标：让内容层级、阅读路径和画面节奏可控。

重点：

- 网格、对齐、留白、密度和比例。
- 主标题、副标题、正文、数据和行动信息的层级。
- 不同尺寸、比例和媒介下的版式迁移。
- 图像、文字、图表和装饰元素的职责分配。

产出：版式原型、网格规则、内容映射和版式 skill。

### 2.3 字体训练

目标：保证文字正确、可读，并与内容气质和版式匹配。

重点：

- 字体分类、性格、字重、字号、行距和字距。
- 中文、拉丁文、数字和标点的混排。
- 字体搭配、信息层级、屏幕可读性和输出适配。
- 字形正确性、文字内容准确性和字体授权。

产出：字体搭配表、排版参数、多语言测试样例和字体 skill。

### 2.4 形式创意训练

目标：建立从概念到视觉形式的转译能力，而不是随机堆叠效果。

重点：

- 概念、隐喻、叙事和视觉符号。
- 几何、有机形、材质、空间、动势和组合逻辑。
- 变体生成、系列一致性和跨媒介延展。
- 原创性、识别度和与任务目标的关联。

产出：形式语法、变体矩阵、系列化规则和形式创意 skill。

## 3. 训练流程

1. 定义任务、受众、媒介、尺寸和不可变条件。
2. 收集合法且与目标相关的参考，标注其可借鉴点和不可复制点。
3. 每轮只改变少量变量，生成可比较的变体。
4. 按统一标准筛选，记录成功条件、失败原因和剩余风险。
5. 使用新内容、新尺寸或新风格复测，确认能力可迁移。
6. 只有结果稳定、边界清晰且可复现时，才沉淀为正式工作流或 skill。

## 4. Skill 结构

一个 skill 只解决一类稳定问题。不将审美、版式、字体、形式创意和工具操作无边界地合并在一个 skill 中。

目录职责：

- `AI_Skills/<专业分类>/` 保存共享规则、具体 Skill 源文件和仍需复测的初始版本。
- 每个专业分类使用局部 `AGENTS.md` 定义读取顺序、共享参考和继承关系。
- `plugins/` 只保存已经通过代表性样本、人工视觉评审和复测门禁的可安装 Skill。
- 初始 Skill 必须链接 `experiments/` 中的来源记录并标明验证状态，不得因位于 `AI_Skills/` 就宣称为正式能力。

每个 skill 必须明确：

- 目标和非目标。
- 触发条件和不应触发的情况。
- 必需输入、可选输入和缺失信息处理。
- 标准步骤、可调变量和不可变约束。
- 输出形式、保存位置和命名规则。
- 评价标准、失败条件和人工审核点。
- 正向案例、反向案例、版本和依赖。

提示词是 skill 的可能组成部分，但只有提示词而没有边界、步骤和评价方法的内容，不得称为完整 skill。

## 5. 评价标准

每次生成或训练至少评估：

- 需求符合度：主题、受众、媒介和品牌要求是否满足。
- 视觉质量：构图、层级、色彩、细节和风格是否统一。
- 版式质量：阅读顺序、对齐、留白、密度和尺寸适配是否合理。
- 字体质量：文字是否正确、可读、授权清晰且与内容匹配。
- 创意质量：概念与形式是否相互支持，是否具有识别度而非无目的奇观。
- 技术质量：是否存在错字、畸变、重复结构、边缘瑕疵、低清细节或无意义水印。
- 可用性：是否可裁切、可延展、可系列化并进入下一制作环节。

评价必须同时记录优点、问题和下一轮只需修改的关键变量。

## 6. 资产、版权与真实性

- 参考图、字体、品牌资产和数据必须记录来源、授权和允许用途。
- 参考用于学习构图、节奏、材质或方法，不用于复制特定作品的独特表达。
- 真实人物、品牌、产品、新闻和数据场景不得伪造事实或隐藏合成性质。
- 未经验证的实验结果不得直接作为正式品牌或生产标准。

## 7. 与工具主线的交接

AIGC 需求交给工具主线时，必须提供：

- 创意目标和受众。
- 不可变的审美、版式、字体和品牌约束。
- 可调参数和允许的变体范围。
- 参考资产、评价标准和通过样例。

工具主线负责把这些要求变成稳定、可重复、可验证的操作流程，不重新定义创意标准。

## 8. 正式能力晋级

- 所有新方向先在 `experiments/` 记录，不直接写入正式 skill。
- 使用 `prompts/creative_experiment_review.md` 和人工视觉审核检查正向、反向样本及授权状态。
- 每次只选择一个晋级层级：提示词、工作流或窄范围 skill。
- 具体门禁见 `workflows/creative_capability_promotion.md`；仓库插件 `codex-design-workflows` 负责流程封装和结构验证。
- 晋级不得移动或删除原始实验，不得用措辞替代验证证据。
