## 初始发现

1. `tools/config/shortcut_config.json` 混用 LF 与 CRLF，导致仓库验证失败。
2. 当前电脑继承系统级 `core.autocrlf=true`，仓库没有本地覆盖，存在双电脑换行漂移风险。
3. VS Code 任务使用 PATH 中的 `powershell.exe`，入口不够明确。
4. `tools/validate_repository.ps1` 有一处 UTF-8 文本读取未显式指定编码。
5. 家里工作站环境文档中的 VS Code 版本和检查结果已过期。
6. `tools/git_status.ps1` 注释保留了电脑专属示例路径。
