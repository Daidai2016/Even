# 视觉资产索引

本目录管理原始素材与来源，不重复维护设计规则。

| 内容 | 位置与用法 |
| --- | --- |
| 品牌手册、Logo、标准色与应用参考 | [brands/](brands/README.md)，先登记实际已有资料 |

| 项目参考、照片、字体样例、设计源文件 | 按实际项目建一个目录，素材少时平铺；同一文件通过相对路径引用 |

通用排印方法只维护在 [typography.md](../AI_Skills/Graphic_Design/references/shared/typography.md)。品牌事实按品牌记录，不写成全局默认值。花卉实验图仍保留在 [原实验](../experiments/floral-texture-visual-skills/) 中。

## 最小资产登记

每个实际项目用一份记录列出：文件名或既有位置、来源、版本、允许用途、确认状态。已有台账可以直接引用，不另建重复台账。未拿到的资料写“待提供”，不生成假的品牌资产。

字体需要登记时，保留：家族/样式、版本、格式、字符数及中文覆盖、西文字距、OpenType功能、可变轴、授权来源与适用范围、Adobe兼容性检查结果。未知信息标明“未核验”。

字体标签采用语言、类型、用途（标题/正文）、载体（排印/屏显）、气质、质量评级；字重记录为家族属性。默认保存样例和索引，字体安装文件仅在允许收录时保存。
