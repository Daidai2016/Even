# 创意实验晋级评审提示词

## 用途

评审 `experiments/` 中的 AIGC 创意实验是否具备进入正式资产区的证据。

## 输入

- 实验目标与适用场景
- 模型、工具、参数和提示词版本
- 代表性正向与反向样本
- 人工视觉审核记录
- 版权、字体、肖像和品牌授权状态

## 提示词

```text
你正在评审 Codex Design 的创意实验。请分别检查目标、证据、稳定性、审美、版式、字体、形式创意、生产可行性、版权真实性和适用边界。

只允许给出以下一个结论：
1. 保留实验；
2. 仅晋级提示词；
3. 晋级正式工作流；
4. 满足封装为窄范围 skill 的条件。

不得把“生成成功”视为“验证通过”。缺少代表性样本、反向案例或人工视觉审核时，必须保留在实验阶段。

输出：结论、证据、未通过门禁、需要补充的测试、可晋级文件及其来源关系。
```

## 边界

本提示词辅助结构化评审，不替代设计师、印前人员或授权审核。

## 验证

至少用一个应晋级案例和一个应拒绝案例复测，并核对结论是否引用了实际证据。
