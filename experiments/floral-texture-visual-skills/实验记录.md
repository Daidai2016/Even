# 花卉肌理视觉 Skill 实验记录

## 目标

建立两项边界明确的初始示例能力：

1. 把用户提供的花卉图片转译为极简几何、纸张颗粒、丝网印刷和克制渐变风格的静态视觉素材或海报。
2. 继承静态画面，把它延展为固定镜头、首尾连续、具有花苞生长、旋转、绽放、轻微摆动和文字渐显的短时长动态海报。

预期场景包括品牌 KV 试验、文化活动海报、社交媒体竖版动态海报和后期排版用主视觉素材。

## 输入与来源

- 规则来源：用户在 ChatGPT 会话“归纳肌理提示词”中确认的设计逻辑，以及本次任务的明确补充。
- 参考资产：当前尚未提供具体花卉图片、品牌手册、字体文件、生成模型、参数或平台规格。
- 权利状态：待每次使用时记录花卉照片、Logo、字体、文案和其他品牌资产的来源、授权与允许用途。
- 版本：初始规则版本 `0.1.0`，日期 `2026-08-22`。

## 输出样本

当前只建立规则、Skill 结构和 Prompt 模板，尚无可用于质量晋级的代表性图像或视频样本。

后续至少补充：

- 不同花型、不同背景和不同画幅的静态正向样本。
- 主体失真、颗粒过重、装饰抢焦、文字错误等静态反向样本。
- 至少两种时长和画幅的动态正向样本。
- 换花、形变、镜头漂移、花瓣闪烁、文字改写等动态反向样本。
- 原始输入、完整 Prompt、模型与版本、参数、生成日期及输出文件路径。

## 评价结果

目前只完成规则层面的结构审查：目标、输入、层级、字体、色彩、静态、动态、输出、禁止项和质量检查均已覆盖。

尚未通过以下人工视觉门禁：

- 审美：层级、平衡、节奏、密度、色彩与材质一致性。
- 版式：不同尺寸下的网格、对齐、留白、阅读顺序和裁切安全。
- 字体：中文、英文、数字和标点在生成与后期排版中的稳定性。
- 形式：几何化与花卉识别度之间的可迁移边界。
- 动态：首尾帧一致性、形态连续性、运动节奏和循环接点。
- 生产：分辨率、色彩模式、印刷表现、视频编码和平台适配。

## 失败案例与边界

已预判但尚待样张验证的失败模式：

- 几何概括过度，花卉品种与轮廓失去识别度。
- 纸张颗粒变成均匀噪点，丝网印刷变成脏污或低清。
- 主体、标题和装饰同时高对比，第一视觉不明确。
- 生成模型写错中文、英文、数字或品牌文案。
- 动态生成中突然换花、增减花瓣、背景呼吸、镜头漂移或边缘闪烁。
- 套色偏差、纹理尺度或渐变在目标输出尺寸下不可用。

非目标：写实植物修图、植物学复原、复杂叙事影片、自由运镜摄影和未经授权的特定艺术家风格复制。

## 晋级决定

当前证据不足以宣称为“已验证正式能力”。本次按用户要求建立可调用的初始示例 Skill 与本地插件结构，但必须保留 `initial-example` 状态；在补齐代表性正反样本、来源授权、模型参数和人工视觉评审前，不得标记为稳定生产标准。

后续复测通过后，再更新插件与 Skill 版本，并在本记录中补充晋级证据。
