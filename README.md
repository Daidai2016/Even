# Codex Design Workspace

AI + Adobe Creative Cloud 自动化设计工作平台。

## 项目定位

Codex Design 是一个基于 OpenAI Codex 的设计自动化工作空间，
用于探索 AI 辅助设计、Adobe 软件自动化以及设计资源管理。

---

## 技术环境

- OpenAI Codex
- VS Code
- Git / GitHub
- Git LFS
- Adobe Creative Cloud

支持：

- Adobe Illustrator
- Adobe Photoshop
- Adobe InDesign
- Adobe Bridge
- Adobe Acrobat

---

## Adobe 自动化方向

计划支持：

### Illustrator

- JSX 脚本
- MCP 自动化控制
- 图形生成
- 批量导出

### Photoshop

- ExtendScript
- 批处理
- 自动化修图

### InDesign

- 排版自动化
- 文档生成

### Bridge

- 素材管理
- 元数据处理

### Acrobat

- PDF 自动处理
