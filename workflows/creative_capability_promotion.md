# 创意能力晋级工作流

## 目标

把通过证据门禁的 AIGC 实验晋级为可复用提示词、正式工作流或窄范围 skill，同时保留原始实验和人工审核记录。

## 输入

- `experiments/` 中的完整实验记录
- 代表性正向与反向样本
- 人工视觉评审
- 来源与授权信息
- 生产规格和适用边界

## 步骤

1. 按 `docs/AIGC_CREATIVE_RULES.md` 核对实验完整性。
2. 使用 `prompts/creative_experiment_review.md` 生成结构化评审。
3. 由设计师复核审美、版式、字体、形式创意和生产适用性。
4. 只选择一个晋级层级：提示词、工作流或 skill。
5. 在正式资产中写明实验来源、版本、依赖、边界和失败案例。
6. 不移动、不覆盖、不删除原始实验。
7. 对晋级资产进行一次正向复测和一次反向复测。
8. 使用 `promote-creative-workflow` skill 的验证脚本检查目录和必需章节。

## 验收

- 结论有代表性样本和人工审核支持。
- 正式资产能追溯到实验、输入、参数和版本。
- 适用范围、非目标、依赖和失败处理清晰。
- 提示词、工作流和 skill 没有无边界合并多个创意问题。
- 交付仍保留必要的 Adobe 与人工生产检查。

## 失败处理

任一关键门禁缺少证据时，停止晋级，将缺失项写回实验记录。不得通过移动文件或修改措辞把未验证结果伪装成正式成果。
