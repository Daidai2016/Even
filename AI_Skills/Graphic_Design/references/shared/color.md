# Color｜色彩系统

记录 `Primary / Secondary / Accent / Neutral / Background / Text` 六种角色，以及色相关系、明度结构和饱和度策略。品牌色和用户指定色为 `LOCKED`。

## 检查

- **PASS**：色彩角色可说明；H1 与背景在目标媒介上有足够可见差异；品牌色数值或批准色域未漂移。
- **WARNING**：屏幕观感成立，但印刷色域、深色模式、色弱可辨性或小字号对比需实测。
- **FAIL**：把高对比误作高饱和；无授权更换品牌主色或主体原色；文字与背景不可读；多种强调色同时争抢 H1。

允许调整 `FLEXIBLE` 的面积比例、辅助色、中性色和局部明度；不得通过滤镜让 `LOCKED` 色彩发生可感知偏移。
