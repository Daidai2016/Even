# Conflict Resolution｜冲突处理

固定优先级：

```text
用户显式参数 > 品牌/项目硬约束 > Skill 专属规则 > 路由规则 > 共享规则 > 默认值
```

处理顺序：识别冲突双方 → 标注各自来源与状态 → 保留更高优先级 → 在低优先级层寻找替代 → 说明影响。不得删减准确内容或静默解除 `LOCKED`。

同级明确要求无法同时满足时，不按固定偏好擅自选赢家。先检查是否为用户后续修正、不同对象或不同阶段；仍影响关键结果时集中询问一次，可提出替代方案但不能当成已获授权。

常见消歧：大标题不等于标题必为 H1；留白多不等于极简；高对比不等于高饱和；颗粒不等于噪点；复古不等于泛黄；动态海报不等于镜头运动。

- **PASS**：冲突、优先级、保留项与替代方案均有记录。
- **WARNING**：取舍将超出已确认预算、工期、可读性底线或关键创意方向，需要用户选择；范围内的常规可逆取舍自行判断并必要时说明，不逐项确认。
- **FAIL**：低级规则覆盖高级规则；擅自改文案、品牌色、画幅或镜头许可；隐瞒无法同时满足的要求。
