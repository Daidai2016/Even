# Codex 平面设计生图与动态视觉规范

版本：`0.1.0`
状态：基础规则；具体创意方向仍须以样张和人工视觉评审验证
适用：Codex Design 中的平面视觉、品牌 KV、海报、产品主视觉、文化墙、肌理素材、动态海报、MG 动画与 Logo 含义演绎

## 1. 规范定位与优先级

本文件是 `codex-design-visuals` 插件的共享视觉规则。具体 Skill 继承本规范，并只补充自身任务需要的窄范围规则。

优先级从高到低为：

1. 用户当前任务中的明确要求。
2. 真实品牌手册、已授权资产、原始文案和生产规格。
3. 具体 Skill 的专用规则。
4. 本共享规范。
5. 默认审美偏好和模型习惯。

如果要求冲突，必须指出冲突、采用的优先级和对结果的影响。不得为了风格统一而擅自修改 Logo、品牌色、产品结构、人物身份、IP 造型或用户文案。

## 2. Design Goal｜设计目标

开始前先定义设计要解决的问题，而不是直接堆叠风格词。

至少明确：

- 设计对象、目标受众和使用场景。
- 第一传播目标：销售、品牌识别、活动主题、情绪建立、信息解释或其他目标。
- 用户第一眼应该感知什么，随后应该理解什么。
- 需要静态图、动态视频、首尾帧、分层素材还是后期排版底图。
- 成功标准、不可变条件和允许变化的范围。

目标信息不足但可以安全推断时，说明假设并继续；假设会改变品牌、事实、版权或生产规格时，先询问用户。

## 3. Input｜输入

### 3.1 内容输入

- 主题、标题、副标题、正文、数据、行动信息。
- 品牌名称、Logo、Slogan、产品或活动信息。
- 文案语言、必须逐字保留的内容和允许改写的内容。

### 3.2 视觉输入

- 原始照片、产品图、Logo、IP、品牌手册、色卡、字体样例。
- 用户参考图、草图、版式示意、首帧、尾帧或既有视频。
- 每项资产的来源、授权状态与允许用途。

### 3.3 生产输入

- 宽高比、像素或物理尺寸、横竖方向、裁切和安全区。
- 屏幕或印刷、RGB 或 CMYK、透明背景、出血与分辨率。
- 动态时长、帧率、平台、编码、循环、音频和字幕需求。

已有信息不得无理由改写。缺失信息应分成“可采用默认值”和“必须确认”两类，不制造伪造品牌或生产事实。

## 4. Design Analysis｜设计分析

### 4.1 主体分析

识别主体类型及其不可丢失的特征：轮廓、比例、结构、材质、颜色、姿态、光影、情绪和品牌属性。风格转译可以概括细节，但不能让主体失去基本识别度。

### 4.2 品牌与语境分析

判断品牌个性、文化语境、受众经验、媒介环境和竞品相似风险。通用风格词必须转译为与本次目标相关的具体视觉选择。

### 4.3 信息与媒介分析

区分核心信息、次级信息、说明信息和可删除信息；评估内容密度、阅读距离、停留时间、裁切风险以及静态到动态的延展条件。

### 4.4 参考图分析

说明参考图可借鉴的构图、节奏、材质、色彩或方法，以及不可复制的独特表达。不得只给出“像参考图”而不说明转译逻辑。

## 5. Visual Language｜视觉语言

视觉语言由形态、材质、光影、空间、色彩、字体和运动共同形成。每次任务应选择少量核心属性，并让所有层级服从同一逻辑。

需要说明：

- 形态：几何、有机、写实、抽象、模块化或手工感。
- 材质：纸张、丝印、油墨、织物、金属、玻璃、塑料、像素或其他。
- 空间：平面、浅空间、舞台式、摄影式或超现实空间。
- 光影：无阴影、平涂、柔光、硬光、局部高光或剪影。
- 节奏：静谧、均衡、跳跃、密集、克制、仪式感或叙事推进。

材质词必须描述尺度、强度和作用位置。避免把“高级、电影感、精致、震撼”当作可执行规则。

## 6. Visual Composition｜视觉构成

画面至少按职责区分以下四类。它们可以视觉融合，但不能逻辑混乱。

### 6.1 Background｜背景

背景提供空间、基调和对比条件。可使用纯色、渐变、纸张、环境、抽象形或低对比纹理。背景不得无目的抢夺第一视觉，也不能因过度空洞而失去完整性。

### 6.2 Visual Subject｜视觉主体

视觉主体承载主要识别或主要信息，可能是产品、人物、Logo、标题、图形、花卉或抽象符号。应明确主体的比例、位置、朝向、裁切、边缘质量、留白和与文字的关系。

### 6.3 Atmospheric Decorations｜氛围装饰元素

装饰元素用于建立节奏、引导视线、平衡留白或强化语境，包括颗粒、线条、光斑、微小图形、印刷偏移和辅助形态。每个装饰元素都应有职责；无职责的装饰应删除或弱化。

### 6.4 Layout｜版式

版式根据内容选择网格、对齐、边距、密度、比例和阅读路径。文字区与图像区要同时规划，不能先生成满版图像后再寻找剩余空隙塞入文案。

需要考虑：

- 标题、主体、品牌标识、说明信息和行动信息的空间关系。
- 横版、竖版、方形和多尺寸裁切时的重排方式。
- 静态关键画面与动态运动路径是否互相冲突。
- 印刷出血、屏幕安全区、平台 UI 遮挡和字幕区域。

## 7. Visual Hierarchy｜非固定视觉层级

禁止把视觉层级写死为“主体 > 标题 > 信息 > 装饰 > 背景”。第一视觉由传播目标决定，可以是标题、Logo、产品、人物、图形、花卉或其他元素。

每次任务至少定义：

- `Primary Focus`：第一眼吸引并承载核心传播目标的元素。
- `Secondary Information`：解释或补充第一视觉的元素。
- `Supporting Elements`：建立节奏、氛围和方向的元素。
- `Background Environment`：提供空间和统一基调的环境。

判断依据包括传播目的、信息重要度、品牌策略、观看距离、停留时间和视觉记忆点。面积不等于重要性。

层级通过尺寸、色彩、明度、清晰度、位置、留白、字体、遮挡、运动和出现时机共同建立。动态中允许层级随时间变化，但每一时刻都应知道观众看什么。

输出设计判断时使用：

```text
Primary Focus: [元素与原因]
Secondary: [元素与原因]
Supporting: [元素与职责]
Background: [环境与对比策略]
Reading / Motion Path: [阅读或运动顺序]
```

## 8. Typography｜字体系统

先决定文字是由生成模型直接生成，还是由后期排版完成。涉及品牌名、活动日期、价格、法律文本、长正文和必须准确的中文时，默认优先后期排版。

### 8.1 标题字体

标题承担识别、情绪或第一视觉，需定义字体类别、字重、尺度、字距、行距、行数、对齐、大小写和与主体的遮挡关系。标题可以高于图像主体，但必须符合传播目标。

### 8.2 正文字体

正文承担阅读和解释，优先可读性、内容准确性和稳定网格。控制每行长度、字号、行距、段间距、对比度和信息密度，不用装饰效果牺牲阅读。

### 8.3 中文

- 核对简繁体、异体字、标点、数字、英文和单位。
- 中文标题可根据气质选择黑体、宋体、圆体、书写性或定制字形，但不得假冒未授权字体。
- 中文正文优先清晰字面、稳定重心和合适行距，避免过度紧排。
- 竖排、避头尾、标点挤压和中西文混排需要专门处理，不把横排参数机械套用。

### 8.4 英文与拉丁文字

- 根据语气选择 serif、sans serif、display、monospace 或 humanist 等类别。
- 核对大小写、连字符、撇号、数字、日期和品牌专名。
- 标题可调整 tracking 与 kerning；正文优先正常词间距、行长和行距。
- 中英文混排需要校准视觉字号、基线、字重和标点间距，而不是只设相同字号。

### 8.5 文字生成与后期策略

- Prompt 中需要占位时，使用明确的留白区或排版占位，不让模型编造无意义小字。
- 图内生成文字必须逐字比对用户输入；错误文字不得作为最终交付。
- 动态文字默认在后期软件中制作，以保证内容、字体和动画可控。

## 9. Color System｜色彩系统

建立角色化色彩，而不是罗列色名：

- 主色：承担品牌或主体识别。
- 辅助色：建立关系和层次。
- 强调色：用于有限焦点、行动或运动峰值。
- 中性色：用于背景、文字和缓冲。

需要说明色相关系、明度结构、饱和度范围、面积比例和对比用途。品牌色值明确时不得凭感觉改色。

屏幕输出考虑 RGB、亮度与平台压缩；印刷输出考虑 CMYK、专色、纸张底色、油墨叠印、总墨量、网点和打样。渐变应避免脏灰、色带和无目的彩虹化。

## 10. Static Image｜静态图像

静态图像需要同时满足构图成立、内容正确和后续可用。

- 先确定母版比例与主要裁切变体。
- 主视觉、文字区、品牌区和安全区在生成前规划。
- 需要后期制作时，优先输出背景、主体、装饰和遮罩等可分层素材。
- 明确像素尺寸、分辨率、色彩模式、透明度和导出格式。
- 检查肢体、花瓣、产品结构、Logo、文字、边缘、重复纹样和无意义水印。
- 对系列图保持构图语法、色彩角色、材质尺度和字体系统一致，同时允许内容变化。

## 11. Motion Design｜动态视觉

动态设计从传播目标和静态关键画面出发，不为“动起来”而增加运动。

### 11.1 首帧与尾帧

- 首帧明确初始状态、主体位置、文字状态、镜头与光线。
- 尾帧明确传播落点，通常需要可停留、可截图、文字完整。
- 首尾帧之间保持主体身份、视觉语言、背景空间和品牌资产一致。
- 需要循环时，额外定义尾帧回到首帧的运动、遮罩或节奏接点。

### 11.2 运动层级

区分主动作、次动作和环境动作。主动作承载叙事或第一视觉；次动作解释结构；环境动作提供呼吸。运动数量、幅度和频率应受控，避免所有元素同时持续运动。

### 11.3 镜头与连续性

固定镜头任务必须明确禁止推拉摇移、视角漂移、焦段变化和背景重建。允许运镜时，要说明运镜目的、方向、速度和落点。连续形变必须保持主体拓扑、颜色和材质稳定。

### 11.4 节奏

用准备、启动、发展、峰值、缓和和停留组织节奏。根据内容选择缓入缓出、弹性、线性、阶梯或停顿；不要让所有动作使用相同速度曲线。

## 12. MG Animation｜MG 动画

MG 动效应使用可解释的图形因果关系：

- 一个驱动元素触发一组相关响应。
- 位移、缩放、旋转、透明度、遮罩、路径和形态变化各有明确职责。
- 运动方向服从版式网格、阅读顺序或自然生长逻辑。
- 同类元素可错峰出现，形成节奏；错峰不是随机延迟。
- 使用预备动作、跟随、超调和回弹时保持克制，避免果冻化。
- 需要循环时优先设计周期关系，而不是简单倒放整段动画。

## 13. Logo Meaning Animation｜Logo 含义动态演绎

Logo 动画必须从品牌含义、构形逻辑和识别资产出发。

1. 明确 Logo 中可解释的形、负形、字母、笔画、模块或象征关系。
2. 选择与品牌概念相关的形成方式，如汇聚、连接、生长、折叠、路径描绘或模块组合。
3. 保持比例、色值、保护区和最终标准形准确；过渡态不能长期误读为另一标志。
4. 尾帧停留在标准 Logo，不用光效、爆炸、粒子和 3D 翻转掩盖概念薄弱。
5. 不虚构品牌寓意。没有官方释义时，把推断明确标记为设计假设并请用户确认。

## 14. Output｜输出

根据任务提供必要内容，不机械输出所有字段。完整设计方案通常包括：

1. 目标与关键假设。
2. 视觉语言与构图说明。
3. 非固定视觉层级映射。
4. 字体与色彩策略。
5. 静态 Prompt、动态 Prompt、负面约束或分层制作说明。
6. 尺寸、格式、色彩空间、时长、帧率等生产规格。
7. 后期排版、Adobe 制作或导出建议。
8. 人工质量检查、授权风险和未验证项。

文件命名应体现项目、用途、画幅、阶段和版本，不使用“最终版”“new”“测试1”等含混名称。

## 15. Forbidden｜禁止项

- 固定“产品或图像主体永远是第一视觉”。
- 在未理解目标时堆砌风格、材质、光效和装饰。
- 擅自改写品牌、Logo、产品结构、人物身份、数据和用户文案。
- 把错误、乱码或伪造小字当作可接受的设计细节。
- 复制特定作品的独特表达，或承诺没有证据的版权与商业可用性。
- 用颗粒、模糊、发光、色差和故障效果掩盖结构问题。
- 动态中无目的运镜、持续呼吸缩放、随机漂浮、突然换主体或不可控形变。
- 只验证文件已生成，不检查实际视觉、文字和生产结果。
- 没有代表性样本与人工审核时，宣称方向已经稳定、验证或可作为品牌标准。

## 16. Quality Check｜质量检查

### 16.1 目标与内容

- 是否满足主题、受众、媒介和品牌要求？
- 文案、Logo、产品、人物、数据与事实是否准确？

### 16.2 视觉

- 第一视觉是否符合传播目标，而非套用固定排序？
- 构图、平衡、节奏、密度、留白、色彩、材质和风格是否统一？
- 主体是否保持识别度，是否出现畸变、重复或边缘瑕疵？

### 16.3 版式与字体

- 阅读路径、网格、对齐、间距、裁切和安全区是否合理？
- 中英文、数字、标点、字体授权、字重、行距和对比是否可用？

### 16.4 动态

- 首尾帧是否一致且能停留？
- 主体、背景、镜头、光线和材质是否连续？
- 运动是否有因果、主次、节奏和清晰落点？
- 是否出现闪烁、跳变、换物、果冻、漂移或文字改写？

### 16.5 生产与权利

- 尺寸、分辨率、色彩空间、透明度、格式、帧率和编码是否正确？
- 来源、授权、字体、品牌、肖像和生成材料状态是否可追溯？
- 是否保留可编辑源文件、Prompt、参数、版本和必要的人工复核记录？

## 17. Skill 继承规则

每个具体视觉 Skill 必须：

- 在入口 `SKILL.md` 中明确链接本规范，并说明触发范围和非目标。
- 只新增本任务特有的输入、步骤、变量、约束、Prompt、失败案例和质量门禁。
- 不复制整份共享规范；若需要改变共享规则，写明覆盖项和理由。
- 明确父 Skill 或共享参考的读取顺序。动态延展类 Skill 应先读取其静态母版 Skill。
- 保留用户输入、品牌资产和生产规格作为最高优先级约束。
- 记录版本、依赖、实验来源、验证状态和人工审核点。
- 将未验证方法标记为实验或初始示例，不用措辞替代证据。

新 Skill 应保持窄范围：一个 Skill 解决一类稳定问题。通用设计原则放在本规范，具体创意转译放在具体 Skill，工具自动化放在对应生产工具或工作流中。
