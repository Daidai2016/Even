# 肌理质感花卉动态海报

版本：`0.1.0`
状态：初始示例，继承 `floral-texture-poster`，待不同视频模型与后期软件复测

## 1. 目标与继承

本 Skill 把已经成立的肌理花卉静态主视觉延展为固定镜头的短动态海报。静态 Skill 中关于花卉识别、背景、主体、装饰、版式、色彩、纸张颗粒、丝网印刷、文字准确性和输出分层的规则继续有效。

本 Skill 只新增：

- 首帧与尾帧状态。
- 花苞生长、旋转、绽放和轻微摆动。
- 文字渐显。
- 固定镜头与形态连续性。
- MG 动效逻辑、时间线、视频 Prompt 和动态质量门禁。

非目标：写实延时摄影、复杂镜头叙事、自由运镜、粒子特效片、角色动画和三维产品动画。

## 2. 必需输入与缺失处理

### 必需输入

- 已确认或至少可用的静态花卉母版。
- 输出画幅和使用平台。
- 目标时长或允许的时长范围。
- 首帧、尾帧及文字是否需要出现。

### 可选输入

- 单独的背景、花卉、花苞、叶片、装饰和文字分层素材。
- 品牌动效规范、音乐、节拍点、循环要求和透明背景要求。
- 指定视频模型、后期软件、帧率、编码和尺寸。

### 缺失处理

- 未给时长时，可提出 `6–10 秒`的短海报建议，但说明这是建议而非固定规则。
- 未给帧率时，根据平台与制作流程建议 `24 / 25 / 30 fps`，不随意混用。
- 未给尾帧时，默认以完整绽放、文字完全可读、画面稳定停留为尾帧。
- 未给循环要求时，不承诺无缝循环；只保证完整起承转合。

## 3. 首帧设计

首帧应与静态母版共享画幅、背景、材质、主色和主要构图。根据叙事选择：

- 花苞首帧：主体位置已确定，但花朵处于紧凑含苞状态。
- 局部开放首帧：保留静态母版的识别轮廓，通过后续分层绽放完成变化。
- 完整花朵首帧：适合轻旋转、摆动和文字渐显，不强制加入生长。

首帧必须说明：

- 花苞或花朵的位置、比例、朝向和裁切。
- 枝叶初始状态。
- 文字是隐藏、轮廓占位还是已显示。
- 装饰元素是否静止、待触发或已存在。
- 镜头固定、背景不重建、光线不变化。

## 4. 尾帧设计

尾帧是传播落点，应能作为独立静态海报停留：

- 花朵完整绽放并回到稳定姿态。
- 文字完整、准确、清晰，不停留在半透明或运动中间态。
- Logo、标题和主体层级符合最终传播目标。
- 装饰元素停止在平衡位置，不遮挡关键信息。
- 至少保留短暂停留，让观众读取。

需要循环时，可选择：

- 花朵摆动回到与首帧相同的相位。
- 以遮罩、色块或花瓣掠过完成接点。
- 设计完整花—花苞的形态闭环，但必须避免明显倒放感。

## 5. 动作语法

### 5.1 花苞生长

- 从枝干或花托产生有方向的伸展，不从空中随机放大。
- 优先使用长度、路径、遮罩和局部比例变化；避免整体呼吸缩放。
- 生长速度由慢到快再缓和，花托与花瓣有前后关系。

### 5.2 旋转

- 旋转用于展示结构或过渡，角度有限且围绕稳定轴心。
- 平面花卉优先轻微二维转动或层间错动，不突然变成三维翻转。
- 旋转速度在绽放前后缓和，不能匀速机械转盘。

### 5.3 绽放

- 花瓣按内外层、前后层或生长方向依次打开。
- 同一朵花的花瓣数量、色彩和身份保持连续。
- 可使用遮罩展开、路径伸展、局部旋转和有限形态变化；避免融化、爆炸或突然换花。

### 5.4 轻微摆动

- 摆动幅度小、周期长、具有枝干支点和衰减。
- 花头、枝干和叶片存在合理的跟随延迟。
- 停留前逐渐减弱，不做无限果冻或无重力漂浮。

### 5.5 文字渐显

- 准确文字优先在后期软件中完成。
- 可用透明度、短距离位移、遮罩擦入或按行错峰。
- 标题与正文分层出现；第一视觉可从花卉转移到标题，也可以相反，但要有传播理由。
- 不改变字形、字距、内容或品牌 Logo 结构。

## 6. MG 动效逻辑

使用“驱动—响应—稳定”的因果链：

```text
枝干轻微生长
→ 花苞出现并沿生长方向伸展
→ 花苞小角度旋转，花瓣分层打开
→ 叶片与装饰产生短暂跟随
→ 花朵轻微回弹并稳定
→ 标题 / 信息渐显
→ 尾帧停留
```

一次只保留一个主要运动事件。背景默认稳定；若需要背景响应，只允许低幅度、低对比、与主动作同向的色块或纹理变化。

## 7. 默认节奏原型

以下百分比是可调整的节奏原型，不是固定时长：

- `0%–12%`：静止辨识或轻微预备动作。
- `12%–38%`：枝干与花苞生长。
- `38%–68%`：有限旋转与分层绽放，形成运动峰值。
- `68%–82%`：轻微摆动、回弹与装饰跟随。
- `76%–94%`：标题、副标题或品牌信息按层级渐显。
- `94%–100%`：完整尾帧停留。

动作可以重叠，但主次要清楚。文字出现时不再安排更强的花朵运动，除非花朵不是当时的第一视觉。

## 8. 固定镜头规则

在 Prompt 中明确：

- locked-off camera / fixed camera。
- no zoom, no pan, no tilt, no dolly, no orbit。
- no focal-length change, no parallax reconstruction。
- background, framing, lighting, palette and texture remain stable。

若视频模型仍产生漂移，优先采用首尾帧约束、分层后期动画或更短分段，不通过增加更多自然语言形容词反复碰运气。

## 9. 视觉层级随时间变化

每个阶段说明第一视觉：

```text
首帧 Primary Focus: [花苞 / 标题 / 其他]
生长阶段 Primary Focus: [运动中的花苞或路径]
绽放峰值 Primary Focus: [完整花朵]
文字阶段 Primary Focus: [标题或品牌信息]
尾帧 Primary Focus: [最终传播对象]
```

标题可以在尾段成为第一视觉，不要求花卉始终占据最高层级。

## 10. 视频输出规范

根据平台明确：

- 画幅与尺寸：如 `1080×1350`、`1080×1920`、`1080×1080`，或用户指定规格。
- 时长与帧率。
- 色彩空间、编码、码率和是否透明背景。
- 是否需要静音、音乐、音效或字幕。
- 首帧、尾帧、海报静帧和循环版本是否单独输出。
- 后期源文件是否需要保留图层、遮罩、路径和可编辑文字。

文件建议：

```text
[项目]_[用途]_[画幅]_motion_v001.mp4
[项目]_[用途]_[画幅]_first-frame_v001.png
[项目]_[用途]_[画幅]_end-frame_v001.png
```

## 11. 视频 Prompt 模板

### 11.1 首帧 Prompt

```text
固定镜头的[画幅与尺寸]肌理质感花卉动态海报首帧。保持静态母版的[背景色、纸张颗粒、丝网印刷、几何色块、版式和安全区]完全一致。主体位于[位置与比例]，呈[紧凑花苞 / 局部开放 / 完整花朵]状态，保留[品种识别特征、枝叶方向和主色]。文字状态为[隐藏 / 占位 / 已显示]。背景、镜头、光线和构图稳定，无空间重建。
```

### 11.2 尾帧 Prompt

```text
与首帧同一固定镜头、同一花卉、同一背景和同一材质语言的尾帧。花朵在原位置完整绽放，花瓣结构、数量、色彩和枝叶身份连续，轻微摆动已经衰减并稳定。[标题“...” / 品牌信息]完整清晰显示，版式层级为[Primary / Secondary / Supporting / Background]，形成可独立停留的完整海报。无镜头位移、无背景变化、无文字错误。
```

### 11.3 视频主 Prompt

```text
基于提供的首帧与静态花卉母版，生成一段[时长]、[帧率]、[画幅]的 MG 风格肌理花卉动态海报。全程 locked-off fixed camera，保持背景、构图、光线、纸张颗粒、丝网印刷色层、几何渐变和色板稳定。

动作顺序：花枝从既定支点轻微向上生长；同一花苞沿生长方向伸展；花苞围绕稳定轴心做有限角度旋转；花瓣按内外层和前后层依次绽放，结构与色彩连续；叶片和少量装饰产生克制的跟随；花朵做一次小幅回弹和低幅摆动后稳定；随后[标题 / 副标题 / Logo]以[透明度 / 短位移 / 遮罩]方式按层级渐显；最终停留在完整尾帧。

运动具有准备、发展、峰值、缓和和停留，使用自然缓入缓出。一次只突出一个主要事件。花卉身份、花瓣数量、主体位置、边缘质感和文字内容始终一致。
```

### 11.4 负面约束

```text
禁止镜头推拉摇移，禁止视角漂移，禁止焦距变化，禁止背景重建，禁止光线闪烁，禁止随机景深，禁止突然换花，禁止增加或减少主花，禁止花瓣融化、爆炸或果冻形变，禁止整体呼吸缩放，禁止无重力漂浮，禁止高频机械旋转，禁止纸纹游走，禁止套色边缘闪烁，禁止颜色跳变，禁止文字改写、乱码、假 Logo、水印和签名。
```

## 12. 分层后期建议

当视频模型难以稳定保持文字、花瓣或纹理时，优先分层制作：

- 背景保持静止或只做极轻的色彩响应。
- 枝干、花苞、花瓣层、叶片、装饰、标题和 Logo 分层。
- 生长用路径或遮罩，绽放用锚点旋转、遮罩与少量形态插值。
- 纸纹和丝印纹理绑定到对象，不让纹理在表面滑动。
- 文字和 Logo 在 After Effects、Premiere、Photoshop 时间轴或其他可控后期软件中完成。

## 13. 失败条件与人工审核

出现以下任一情况需返工或改用分层后期：

- 主体身份、花瓣结构、背景或镜头不连续。
- 花苞生长只是整体放大，或绽放变成爆炸、融化、换物。
- 摆动无支点、幅度过大或无法稳定停留。
- 标题错误、字形扭曲、阅读时间不足。
- 纸纹、网点、套色边缘随帧闪烁或漂移。
- 首帧与尾帧不能作为同一系列的静态海报。

人工审核至少检查逐帧一致性、运动节奏、视觉层级、文字准确、品牌资产、循环接点、平台压缩和最终文件可播放性。
