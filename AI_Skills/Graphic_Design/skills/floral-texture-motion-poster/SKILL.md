# 肌理质感花卉动态海报

把已经成立的静态花卉主视觉延展为短时长、固定镜头、结构清楚的动态海报。运动必须强化花卉生长与视觉层级，不得破坏原有构图、品牌识别和文字可读性。

## 继承与读取顺序

1. 读取共享规范：[平面设计生图与动态视觉规范](../../references/平面设计生图与动态视觉规范.md)。
2. 读取父 Skill：[花卉图片转肌理质感素材](../floral-texture-poster/SKILL.md)及其[完整规则](../floral-texture-poster/references/花卉图片转肌理质感素材.md)。
3. 读取本 Skill 的动态规则与视频 Prompt 模板：[肌理质感花卉动态海报](references/肌理质感花卉动态海报.md)。

若父 Skill 与本 Skill 冲突，以用户当前要求优先，其次以本 Skill 的动态专用规则优先；未被覆盖的静态规则继续有效。

## 工作方法

1. 先确认静态母版已经满足构图、色彩、材质和文字区要求；未成立的静态画面不直接动画化。
2. 明确首帧、尾帧、时长、画幅、播放平台、是否循环和文字出现时机。
3. 把运动拆成少量主动作：花苞生长、有限角度旋转、花瓣分层绽放、轻微回弹或摆动、文字渐显。
4. 固定镜头和主要构图；除非用户明确要求，不做推拉摇移、景深漂移或背景空间重建。
5. 使用 MG 的因果关系组织动画：驱动元素先动，关联元素依次响应，装饰最后跟随；一次只突出一个主要事件。
6. 输出分镜状态、节奏说明、首帧 Prompt、尾帧 Prompt、视频主 Prompt、负面约束与人工检查项。用户要求生成视频时，再调用可用的视频生成能力。

## 不可变约束

- 首帧与静态母版的主体位置、色彩关系、材质语言和画幅一致。
- 尾帧必须是可停留的完整设计画面，不以动作中间态或文字半透明状态结束。
- 生长和绽放保持同一朵花的结构连续，不突然换花、增减主花或发生不受控形变。
- 摆动幅度克制，不制造漂浮、果冻、呼吸式缩放或无重力感。
- 文字只做可解释的显现、位移或遮罩动画，不扭曲字形，不让生成模型改写文案。
- 未经逐帧与人工视觉审核，不把输出称为已验证动态品牌标准。

## 交付检查

- 时间线能说明每个动作的开始、峰值、缓和与停留。
- 第一视觉在运动过程中仍然明确，层级变化服务传播目的。
- 首尾帧构图连续，循环需求有明确接点。
- 固定镜头、主体一致性、文字准确性和边缘闪烁均有负面约束。
- 输出规格包含尺寸、时长、帧率、编码或透明背景要求（如适用）。
