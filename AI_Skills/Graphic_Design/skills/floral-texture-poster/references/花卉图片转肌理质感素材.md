# 花卉图片转肌理质感素材

版本：`0.3.2` / 2026-09-10（提示写法修订，验证状态不变）
状态：初始示例；默认原色转绘，指定换色为可选模式，并覆盖完整花卉几何化；待多花型、多画幅和不同生成模型复测

## 1. 能力目标

将参考图中的完整花卉主体转绘为极简主义平面几何插画：强调重质感与整体几何感，以重叠、半透明、带颗粒纹理的矩形和几何色块构成花瓣，并用同一套几何、渐变、叠印、颗粒纸张和丝网印刷语言处理花蕊、花心或蒴果、花茎、花托、叶片及枝条。禁止只几何化花瓣、其余部分仍保留写实摄影质感。

默认采用“原色转绘”：保留参考图中花瓣、花蕊、花心或蒴果、花茎、花托、叶片和枝条原有的色相、明度、饱和度、冷暖、对比及渐变关系，只改变形态、材质和印刷语言。只有用户明确要求换色时，才采用开放目标色参数；红色、橙红色、淡紫色和橙黄色仅为换色示例，不是固定色库。

最终目标不是只得到一张生成图，而是得到经过 Photoshop 或 Illustrator 整理、满足目标尺寸和交付格式的静态母版。该母版也可作为动态花卉 Skill 的首尾帧和分层素材来源。

## 2. 生成前参数确认

### 2.1 必须确认

术语统一：本文使用“花茎”表示连接花朵的茎部；用户提示词中的“花径”按语境规范为“花茎”，不改变其设计意图。

- `reference`：花卉参考图；没有图片时需要花型、姿态、花瓣层次和构图描述。
- `color_mode`：默认 `preserve-source`（保留原图配色）；仅当用户明确要求改色、提供目标色或要求配色变体时使用 `recolor`。
- `source_color_map`：分析花瓣、花蕊、花心或蒴果、花茎、花托、叶片和枝条的实际颜色、内部色差与渐变关系；保色模式通常无需逐项追问，只有参考图含义不清时才确认。
- `target_petal_gradient`、`target_stem_gradient`、`target_stamen_color` 与 `other_flower_parts`：仅在 `recolor` 模式中确认；支持任意自然语言颜色、HEX/RGB/CMYK/Pantone 色值、色卡或多段渐变。
- `use_case`：素材、KV、海报、社交媒体、印刷或动态母版。
- `canvas`：宽高比、像素或物理尺寸。
- `background`：用户明确指定时设为 `LOCKED`；仅在未指定时默认干净白色。
- `deliverable`：PNG/JPG、分层 PSD、可编辑 AI、两者兼有或仅概念图。
- `text_policy`：用户明确要求文字时设为 `LOCKED`，确认准确文案、语言、位置、排印及出现次数；需要可编辑排字时再确认后期软件；仅在未指定文字时默认无文字。

### 2.2 对话规则

默认保色模式不把目标颜色视为缺失参数。只需说明“将保留原图配色，只转换风格”，然后确认生产规格。参考图色彩无法可靠识别时再询问。

用户明确要求换色时，才集中询问：

```text
开始生图前还需要确认：
1. 我识别到原图各部位配色为[原图色彩分析]，是否准确？
2. 哪些部位需要换色，哪些部位必须保留原色？
3. 目标花瓣、花茎、花蕊及其他指定部位分别使用什么颜色或渐变？
4. 成品尺寸、用途以及 PNG、分层 PSD、可编辑 AI 等交付要求是什么？
```

不要重复询问用户已经给出的内容。若用户没有提出换色，不得主动把换色示例当成推荐方案；直接继承原色。不得默认具体花卉身份或生产尺寸。

## 3. 参考图分析与视觉转译

先提取外轮廓、花瓣数量与层次、开放程度、花蕊放射结构、花心或蒴果、花茎、花托、叶片与枝条方向、主色和识别点。几何化必须覆盖完整花卉主体：用矩形、梯形、弧形、椭圆和有机几何块概括花瓣，并用同一造型语法概括花蕊、花心、蒴果、花茎、花托、叶片和枝条；保持生长方向与主体身份，避免随机拼贴。

视觉层级按传播目标决定，不写死：花卉可为第一视觉；如果后期加入标题，标题也可以成为第一视觉。默认素材模式下，主花承担第一视觉，花茎与花心为第二信息，纸纹与叠印为辅助，白色背景提供负空间。

## 4. 默认视觉配方

### 背景

- 用户未指定背景时，默认干净白色、均匀、稳定，不出现环境、场景、强阴影和颜色漂移；用户指定的彩色、透明或其他背景优先并设为 `LOCKED`。
- 允许可感知但非常克制的纸张纤维；不得让白底变灰、变脏或抢焦。

### 花卉主体

- 花瓣由重叠、半透明、具有颗粒纹理的矩形和几何色块构成；默认严格继承原图花瓣的粉、红、紫、黄等实际色彩和细微渐变，并保持生长方向。
- 花蕊、花心或蒴果、花茎、花托、叶片和枝条也必须使用平面几何形、色块分段、渐变、叠印和颗粒纹理统一转绘。
- 各部位可使用不同几何形态，但边缘语言、透明叠印、纹理尺度和色彩逻辑必须属于同一系统。
- 花茎、花蕊及其他部位默认继承原图颜色、内部明暗和冷暖差异，同时保留可识别结构。
- 只有 `recolor` 模式才应用用户指定的目标渐变或目标颜色；未指定换色部位继续保留原色。
- 不允许把写实照片花茎、叶片、蒴果或花蕊直接粘在几何花瓣上。

### 材质

- 纸张颗粒具有尺度变化和局部密度，不是均匀数字噪声。
- 丝网印刷使用有限色层、轻微油墨不均与克制套色偏差。
- 纹理绑定主体，不模糊几何边缘；在目标尺寸下仍清楚可用。

### 版式与装饰

- 用户未指定时，默认单主花、留白充分、无文字、无额外装饰；用户给出的花朵数量、文字与装饰要求均设为 `LOCKED`。
- 如需装饰，只能加入服务平衡、视线或节奏的少量几何元素。
- 不自动加入第二朵花、假文字、Logo、签名或人物。

## 5. 配色模式

### A. 默认：保留原图配色

- 不改变任何部位的主色角色和渐变方向。
- 几何色块从原图局部取色关系中建立，不用另一套主题色替换。
- 纸张颗粒、透明叠印和丝印油墨可以造成克制的自然明暗变化，但不得形成可感知的新配色。
- 质量检查以参考图为基准；若观者首先感知到“换了一套颜色”，则保色失败。

### B. 可选：指定换色

仅在用户明确要求时启用。以下四组只用于展示参数如何填写，不构成枚举、默认色库或允许范围。

## 6. 换色示例组合（非限定选项）

原图花瓣渐变从实际输入识别；用户可指定任意目标花瓣渐变、目标花茎渐变和目标花蕊颜色。下列组合仅用于用户明确选择整组配色时；只要求改变花瓣时，花茎、花蕊等未指定部位仍保留原色，不自动采用示例绿色或黑色。未提出换色时不得调用这些示例。

### A. 红色渐变 + 黑色雄蕊

- 花瓣：红色同色系几何渐变。
- 花茎：翠绿色渐变色块。
- 花心：细节丰富的黑色雄蕊，形成鲜明对比。

### B. 橙红色渐变

- 花瓣：橙红色渐变，控制红橙比例，不变成霓虹或高光 3D。
- 花茎：翠绿色渐变色块。
- 花心：按参考图；未确认时不要凭空添加黑色雄蕊。

### C. 淡紫色

- 花瓣：淡紫色为主，可用同色系浅紫到中紫的微妙几何渐变。
- 花茎：翠绿色渐变色块。
- 保持明度对比，避免白底上主体发灰或消失。

### D. 橙黄色渐变 / 橙色核心

- 花瓣：橙黄色渐变，主体核心可偏橙色。
- 花茎：翠绿色渐变色块。
- 控制黄色高光，确保纸纹和花瓣边界可辨。

## 7. 中文主 Prompt 模板

按[提示编写指南](../../../references/Prompt_Framework.md)填写实际需要的内容，删除无关字段。图1须对应实际查看的花卉原图；无图时改用用户提供的主体描述，不虚构图像输入。工具设置、后期步骤和交付路径单列。

### 默认原色转绘模板

```text
为{用途}制作完整花卉的平面几何肌理素材。图1提供主体结构与原始配色，只改变造型和材质语言。

整株花卉统一概括为矩形、梯形、弧形与有机几何色块，使用半透明叠印、纸张颗粒和丝印油墨质感；花瓣、花蕊、花心或蒴果、花茎、花托、叶片与枝条均采用同一视觉语言，不残留局部写实摄影质感。
```

### 指定换色模板

```text

整株使用几何色块、半透明叠印、纸张颗粒与丝印油墨表现；花瓣、花蕊、花心或蒴果、花茎、花托、叶片与枝条统一处理，不混入写实摄影残片。
保持{已确认画幅、构图与留白}，背景为{用户指定背景；未指定时为干净白色}，文字为{已确认准确文字及排印或后期留白策略；未指定时无文字}。
```

## 8. 四组换色示例

以下是用户明确要求换色时可放入第 7 节模板的配色句，不是独立完整提示。原图颜色来自实际读图；花茎、花蕊与其他部位没有明确换色要求时保留原色。背景、文字与构图继续沿用用户硬锁，不附带白底、无字或新布局。

### 红色渐变

```text
将花瓣从{实际原图渐变}改为浅朱红至深红的同色系渐变，用几何色块与叠印表达过渡。花茎、花蕊和其他部位保留原色；如有明确指定的目标色，使用该目标色。
```

### 橙红色渐变

```text
将花瓣从{实际原图渐变}改为{用户确认起止色}的橙红渐变，色块过渡克制、轮廓清楚。花茎、花蕊和其他部位沿用已确认配色。
```

### 淡紫色渐变

```text
将花瓣从{实际原图渐变}改为浅紫至中紫的柔和几何渐变。花茎、花蕊和其他部位保持已确认配色，不让花瓣的新色扩散到其他部位。
```

### 橙黄色渐变

```text
将花瓣从{实际原图渐变}改为橙黄色至橙色的几何渐变，保留纸纹及花瓣边界的可辨识度。花茎、花蕊和其他部位保持已确认配色。
```

以上具体起止色仅为示例，必须替换为用户明确指定的色值或方向；未指定且不影响核心方向时才作为标明的最小假设。

## 10. PS / AI 后期完稿

### Illustrator 路线

1. 置入选定生成图并锁定参考层。
2. 重建完整花卉外轮廓、花瓣几何块、花蕊、花心或蒴果、花茎、花托、叶片和枝条；保持可编辑路径。
3. 按 `花瓣前层 / 花瓣后层 / 花蕊 / 花心或蒴果 / 花茎 / 花托 / 叶片和枝条 / 材质 / 背景` 命名分层。
4. 用透明度、混合模式、渐变和剪切蒙版重建叠印关系；避免无意义描边。
5. 检查路径节点、重叠边缘、出血与色彩模式；保存 AI，并按需求导出 PDF/SVG/PNG。

### Photoshop 路线

1. 建立非破坏性图层、智能对象和蒙版，清理生成瑕疵与背景杂色。
2. 修正花瓣边缘、花蕊细节、花心或蒴果、花茎连接、花托、叶片、枝条和不合理形变；清除所有写实摄影残留。
3. 用可控纸纹、网点或油墨层建立质感；纹理随主体，不覆盖整个画面。
4. 校正渐变断层、色偏、白底纯净度与目标尺寸锐度。
5. 按用途保存分层 PSD，并导出 PNG/JPG/TIFF；印刷文件检查 CMYK、分辨率和出血。

### 双软件路线

Illustrator 负责几何结构与可编辑矢量，Photoshop 负责纹理、色彩和最终合成。用户需要图内文字时可直接生成并逐字检查；标准 Logo、精确字体和可编辑排字在可控后期中加入并复核。

## 11. 完成与质量门禁

以下任一情况存在时，不得标记为最终完成：

- 关键生成参数未经确认。
- 花卉失去核心识别，花瓣变成随机色块。
- 保色模式下，任一主要部位与原图出现明显色相、明度、饱和度、冷暖或渐变方向漂移。
- 换色模式下，原图色与目标色被混为一个参数，或指定换色部位的目标颜色未经确认。
- 只有花瓣完成几何化，其他花卉结构仍为写实摄影、写实渲染或不统一风格。
- 用户未指定背景时，默认白色背景变脏、变色或出现多余元素；用户已指定背景时，锁定背景发生偏移。
- 纸纹、网点、套色和渐变互相竞争，目标尺寸下不可用。
- 只完成生图，尚未执行约定的 PS/AI 后期。
- 缺少约定的可编辑源文件或最终尺寸导出。
- 图内出现错误文字、乱码、假品牌信息或未授权资产。

若软件不可用，交付状态必须写为“生成素材完成，PS/AI 后期未执行”，并附具体图层、修复、色彩、材质与导出清单。
