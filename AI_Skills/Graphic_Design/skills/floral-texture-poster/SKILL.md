# 花卉图片转肌理质感素材

把花卉参考图转译为可用于商业版式的肌理化平面视觉。保留花卉的核心识别特征，同时允许对轮廓、比例、色块和材质进行设计性概括。

## 使用前读取

1. 读取共享规范：[平面设计生图与动态视觉规范](../../references/平面设计生图与动态视觉规范.md)。
2. 读取本 Skill 的完整规则与 Prompt 模板：[花卉图片转肌理质感素材](references/花卉图片转肌理质感素材.md)。
3. 若参考图来源、授权或允许用途不清楚，先标记风险；不要声称可以商业使用。

## 工作方法

1. 明确用途、媒介、尺寸、受众、必须保留的花卉特征与禁止改变项。
2. 从参考图提取轮廓、花瓣层次、枝叶方向、主色关系和最有辨识度的结构；不逐像素复制。
3. 先决定第一视觉焦点，再安排背景、花卉主体、氛围装饰和文字区。第一视觉可以是花卉，也可以是标题，不固定排序。
4. 用几何化色块建立主体，用纸张颗粒、丝网印刷套色偏差和克制渐变建立材质；装饰元素只服务节奏、视线和留白。
5. 默认把准确文字留给后期排版。只有用户明确要求图内文字时，才把文字纳入生成，并逐字核对。
6. 输出一份设计判断、一份可直接使用的主 Prompt、一份负面约束和必要的后期制作建议。用户要求生成图像时，再调用可用的图像生成能力。

## 不可变约束

- 不擅自修改品牌色、Logo、产品信息、用户文案和明确指定的花卉品种特征。
- 不把纸张颗粒理解为满屏噪点，不把丝网印刷理解为脏污或低清晰度。
- 不同时堆叠大量互相竞争的装饰、光效、3D、摄影和复古效果。
- 不复制在世艺术家或特定作品的独特表达；只描述可泛化的视觉属性与制作方法。
- 未经代表性样张与人工视觉评审，不把输出称为已验证品牌标准。

## 交付检查

- 核心花卉仍可识别，几何化不是随机变形。
- 背景、主体、装饰、文字区职责清楚，边缘与负空间可用于版式。
- 纸感、套色和渐变相互协调，细节在目标尺寸下成立。
- Prompt 中已写明画幅、构图、层级、色彩、材质、文字策略与禁止项。
- 明确列出仍需人工检查的字体、版权、品牌、印刷或视频衔接问题。
