# Quality gates

Use every applicable gate before promotion:

- Goal: the creative objective and intended production use are explicit.
- Evidence: representative positive and negative outputs are preserved.
- Stability: repeated runs show bounded, explainable variation.
- Aesthetics: hierarchy, balance, rhythm, density, color, and style coherence pass human review.
- Layout: grid, reading order, alignment, spacing, and content mapping remain usable.
- Typography: font choice, hierarchy, multilingual behavior, and output consistency are verified.
- Form: the visual idea supports the message and can generate a coherent series.
- Production: dimensions, resolution, color mode, transparency, editability, and export requirements are known.
- Rights: reference assets, fonts, likenesses, brands, and generated material have traceable usage status.
- Boundaries: failure cases, non-goals, dependencies, and manual review points are documented.

If any required gate lacks evidence, keep the work experimental and state the missing evidence.
