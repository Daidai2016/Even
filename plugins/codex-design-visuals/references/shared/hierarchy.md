# Hierarchy｜视觉层级

先按传播目标定义 `H1 / H2 / H3`，必要时增加 H4 辅助信息与 H5 氛围信息。主体、标题、产品或 Logo 都可能成为 H1，不得写死。

## 检查

- **PASS**：可明确指出唯一 H1；H1 与 H2 在尺度、对比、位置或密度上至少有一项明显级差；阅读顺序与任务目标一致。
- **WARNING**：H1 可识别，但 H2/H3 距离过近，或装饰元素在缩略图中抢焦。
- **FAIL**：多个元素争抢 H1；准确内容被装饰遮挡；Logo 被无目的放大；视觉顺序与信息优先级相反。

优化时只调整 `FLEXIBLE` 的尺度、对比、位置和密度。已锁定为 H1 的元素不得被共享规则降级。
