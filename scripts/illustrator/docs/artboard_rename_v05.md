# 画板批量重命名 v05

在 Illustrator 2024 或更新版本中打开文档，通过“文件 → 脚本 → 其他脚本…”运行 `scripts/illustrator/jsx/artboard_rename_v05.jsx`。

## 命名模式

下拉菜单提供以下 7 项，默认选择第一项。以下示例使用文档“展架.ai”、第 1 个画板、换算尺寸 800×2000mm，文档画板总数不超过 99 个。

| 模式 | 示例 |
| --- | --- |
| 序号+文档+尺寸名 | 01_展架_800×2000mm |
| 序号+文档名 | 01_展架 |
| 序号+尺寸名 | 01_800×2000mm |
| 文档名+尺寸名 | 展架_800×2000mm |
| 仅序号 | 01 |
| 仅文档名 | 展架 |
| 仅尺寸名 | 800×2000mm |

“命名用文档名”输入框默认填入去掉扩展名的原文档名，可手动简化为项目或内容名称，支持中文、数字和常规符号，首尾空白自动去除。修改后实时更新预览，仅影响画板名称，不修改实际文件名。

含文档名的四种模式使用该输入框；空白或控制字符会阻止执行。不含文档名的三种模式禁用该输入框，保留已输入内容，切回时可继续使用。

各组成部分沿用下划线连接，尺寸固定使用乘号 `×`，例如 `01_发布会_主背景_800×2000mm`。

序号依据画板面板顺序。整个文档不超过 99 个画板时使用两位数字（01～99）；超过 99 个时统一使用三位数字（001、002…100）。仅处理当前画板或指定范围时，仍以整个文档的数量确定位数，保留原画板编号。1000 及以上保留完整数字，不截断。

同名画板自动追加短横连接的大写字母后缀：`-A`、`-B`…`-Z`、`-AA`、`-AB`…；超过两位容量继续 `-AAA` 等。已占用的名称会跳过。名称唯一时不额外加后缀，预览显示最终名称。

## 范围、比例与单位

支持全部画板、当前画板、指定编号（例如 `1,3,5-8`）。如果未处理的画板彼此重名，会提示扩大范围，以保证每次成功执行后整个文档名称唯一。

含尺寸的模式启用尺寸设置；其他模式禁用尺寸设置。比例为“图上 : 实际”，提供 1:1、1:10、1:100、自定义正数比例。80×200mm 的画板按 1:10 命名得到 800×2000mm。混合比例请分范围处理。

单位可选 mm、cm、m、px；换算完成后四舍五入到整数。px 按 Illustrator 的 1pt = 1px，与导出 DPI 无关。取整为 0 时提示改用较小单位。大画布先还原文档内部比例，再应用制作比例。

脚本只修改画板名称，不自动保存；取消不修改文档。写入失败时尝试恢复本批原名，并报告恢复异常。

## 版本与验证

v01～v04 保留。v05 增加“命名用文档名”输入框，保留七种下拉模式与默认项，以及数字位数、尺寸换算、范围选择、字母去重与署名。采用 ExtendScript ES3 语法。

运行测试：`node scripts/illustrator/examples/artboard_rename_v05_test.js`。覆盖命名用文档名的中文符号、首尾空白、无效输入与不适用模式，以及七种输出、99/100 位数切换、1000 个名称、重名处理、尺寸换算、范围和失败回滚。Node 验证不代表 Illustrator 真机验证；v05 尚未在 Illustrator 内实测。
