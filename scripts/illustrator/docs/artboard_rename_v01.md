# 画板批量重命名 v01

脚本：`scripts/illustrator/jsx/artboard_rename_v01.jsx`。参考用户提供的操作界面与功能介绍独立实现，未使用第三方脚本源代码。

## 使用方法

1. 在 Illustrator 中打开需要处理的文档。
2. 选择 **文件 → 脚本 → 其他脚本…**，打开上述 JSX 文件。
3. 选择命名模式、应用范围、比例尺和单位，核对新旧名称预览。
4. 点击“确认重命名”，检查画板面板后自行保存文档。

设计目标为 Illustrator 2024（28.x）及更新版本，使用原生 ExtendScript ES3 和 ScriptUI，无需额外插件。也可将脚本自行复制到 Illustrator 安装目录的 `Presets/<语言>/Scripts` 文件夹，重启后从“文件 → 脚本”菜单运行。

## 四种命名模式

假设文档为 `展架.ai`，画板为 80×200mm，比例为 1:10，单位为 mm：

| 模式 | 输出示例 |
| --- | --- |
| 文档名 | 展架 |
| 尺寸名 | 800×2000mm |
| 文档+尺寸名 | 展架_800×2000mm |
| 自定义名称：`画板 @_#_$` | 画板 01_展架_800×2000mm |

自定义名称支持简体中文、数字、空格及常规符号。`@` 为画板面板顺序编号，至少两位；指定范围不会重新编号。`#` 为去掉常见文件扩展名的文档名称，未保存文档使用 Illustrator 的当前文档名。`$` 为画板尺寸。代码可重复、任意组合，也可完全不使用代码。

输入 `\@`、`\#`、`\$` 可保留符号本身，输入 `\\` 可保留一个反斜杠。空白名称和控制字符不允许；重复名称允许，预览会提示目标范围内的同名情况，不会擅自附加编号。

## 比例、尺寸和单位

- 比例尺提供 **1:1（默认）、1:10、1:100、比例自定义**。自定义两侧均可输入正整数或小数，如 1:20、2:1。
- 比例含义是“图上尺寸 : 实际制作尺寸”。计算为画板尺寸 × 右侧数值 ÷ 左侧数值。
- 单位为 **mm、cm、m、px**，分别表示毫米、厘米、米、像素。格式固定为“宽×高单位”。
- 先完成比例及单位换算，再四舍五入为整数，不保留小数。例如 1499mm 换成 m 得到 1m；这是整数精度的结果。
- 小尺寸采用 m 时可能出现 0m，预览会提示，可切换 cm 或 mm。脚本不会把 0 擅自改成 1。
- px 采用 Illustrator 的 1pt = 1px，与文档栅格效果分辨率及导出 DPI 无关。
- 获取的是画板边界尺寸，不包含出血、图稿越界部分或裁切标记。宽和高保持画板方向。
- 大画布文档按 `Document.scaleFactor` 还原尺寸，再应用制作比例；大画布内部缩放与人为按 1:10 制图是两件事。若 Illustrator 界面显示的画板尺寸已经是实际制作尺寸，使用 1:1。

同一批目标采用相同比例。只有部分画板采用 1:10 时，请选择“当前画板”或“指定编号”（如 `1,3,5-8`）分批执行。脚本不会推测画板的制作比例。

## 修改范围与异常

只修改当前文档中指定画板的名称。取消不修改文档；执行不改变画板尺寸、位置、图稿或文档单位，也不自动保存。写入失败会尝试恢复本批原名称；若恢复失败，报告具体画板编号。完成提示包含改名数量、未变数量和耗时。
