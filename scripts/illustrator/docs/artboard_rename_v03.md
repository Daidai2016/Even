# 画板批量重命名 v03

脚本位置：`scripts/illustrator/jsx/artboard_rename_v03.jsx`。在 Illustrator 中打开文档，通过“文件 → 脚本 → 其他脚本…”选择该文件运行。脚本内“使用说明”末尾空一行显示作者与联系邮箱；原生提示框显示纯文本邮箱，本文末尾提供邮件链接。

## 命名与编号

保留四种模式：文档名、尺寸名、文档+尺寸名、自定义名称。自定义支持简体中文、数字和常规符号，`@` 表示画板面板中的序号（至少两位），`#` 表示去掉扩展名的文档名称，`$` 表示换算后的画板尺寸。例：`画板 @_#_$`。需要符号本身时输入 `\@`、`\#`、`\$`；输入 `\\` 保留一个反斜杠。

四种模式都自动处理重名：

- 同批生成相同名称时，按画板面板顺序全部追加 `-A`、`-B` 等编号，例如 `展架-A`、`展架-B`。
- 名称唯一时不额外编号。自定义名称中已经使用 `@` 且无冲突时，不再附加编号。
- 检查整个文档，与范围之外的画板重名时，也给目标画板编号。已占用的编号会跳过。
- 预留所有原始候选名称，避免生成的编号占用其他画板原本唯一的名称。例如候选名为 `展架、展架、展架-A`，结果为 `展架-B、展架-C、展架-A`。
- 自动后缀按同名组计数，与 `@` 的原始画板编号含义不同。顺序为 A 至 Z，然后 AA、AB…AZ、BA…ZZ；超过两位容量时继续 AAA 等，确保不重名。连接符为短横 `-`。
- 预览显示最终去重名称，执行前再次计算。相同文档状态及设置产生相同结果。

应用范围仍支持全部、当前和指定编号（例如 `1,3,5-8`）。范围外画板保持原名；如果范围外画板彼此已经重名，脚本会阻止执行并提示扩大范围。这样每次成功执行后，整个文档的画板名称均不重名。

## 比例与单位

比例尺提供 1:1、1:10、1:100、自定义，含义为“图上 : 实际”。例如 80×200mm 的画板按 1:10 命名为 `800×2000mm`。自定义两侧接受正整数及小数。

单位可选 mm、cm、m、px。先换算，最后四舍五入为整数，格式为“宽×高单位”。px 按 Illustrator 的 1pt = 1px；与导出 DPI 无关。选用 m 导致尺寸取整为 0 时会提示改用更小单位。

同批使用同一比例，混合比例画板请分范围运行。大画布按文档内部比例还原后再应用制作比例。脚本只修改画板名称，不调整画板、图稿或文档单位，不自动保存；取消不修改文档。失败时尝试恢复本批原名，并报告恢复异常。

## 版本与验证

v01、v02 保留不变。v03 将重名编号改为短横连接的大写字母，并将署名与联系作者信息放在说明末尾，前空一行。其他功能沿用原版本。按 Illustrator 2024+ 的 ExtendScript ES3 编写。

自动测试：`node scripts/illustrator/examples/artboard_rename_v03_test.js`。

覆盖 v01 的尺寸、模板、范围、非法输入和回滚测试，并增加四种模式的自动编号、与非目标画板冲突、编号占用、候选名预留、重复运行、范围外重名拦截、1000 个同名候选与署名检查。

v01 已在 Illustrator 2026（30.8.2）实测。本次 v03 的新增逻辑通过 Node 测试；尚未进行 v03 Illustrator 真机验证，v01 的真机结果不等同于 v03 已实测。
