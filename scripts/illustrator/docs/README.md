# 六、1:10大画面制作流程


Illustrator适用于：

大尺寸矢量画面的比例化制作。


1:10制作比例适用于：


- 矢量图形
- 文字
- 版式元素
- 图形化设计内容



不适用于：


- 照片
- 位图图像处理
- Photoshop图像效果



典型流程：


Illustrator：

矢量图形、文字、版式制作


↓

按照制作比例建立文件


↓

输出生产文件


↓

进入后续图像处理或制作流程



说明：


1:10制作属于矢量设计生产方式。

不作为位图处理方案。
