# 二、Adobe自动化技术基础


Adobe自动化主要使用：


- ExtendScript
- JSX
- JavaScript接口


不同Adobe软件：

通过各自应用程序对象模型（DOM）

实现自动化控制。


---

# 三、ExtendScript开发规则


## 1. 兼容性要求


Adobe ExtendScript环境主要基于：

JavaScript ES3。


开发时：

必须考虑Adobe版本兼容性。


避免主动使用：

- let
- const
- 箭头函数 =>
- class
- import
- export


推荐使用：

- var
- function
- try/catch



---

## 2. 脚本目标


Adobe脚本主要用于：


- 自动创建
- 自动修改
- 自动处理
- 自动保存
- 自动输出


脚本应减少人工操作。



---

# 四、Adobe文件处理规范


所有文件操作必须明确：


- 输入文件
- 输出文件
- 文件路径
- 文件格式
- 覆盖规则


禁止：

未经确认覆盖原始生产文件。


推荐流程：


读取文件

↓

处理文件

↓

生成输出

↓

记录结果



---

# 五、无人值守运行原则


Adobe生产脚本应支持：

无人值守运行。


禁止依赖：

- 手动点击确认
- 中途选择文件
- 人工处理异常



---

## 异常处理原则


单个文件异常：

不得导致整个任务停止。


正确流程：

发现异常
↓
记录文件
↓
记录原因
↓
继续执行
↓
生成报告

# 七、脚本运行安全原则


## 1. 保存前确认


自动保存文件前：

必须确认：


- 文件路径正确
- 文件格式正确
- 输出目标正确



---

## 2. 关闭文档


处理完成后：

应根据任务需要：


- 保存
- 关闭
- 清理资源


避免：

大量批处理导致应用程序资源占用。



---

## 3. 状态恢复


脚本运行过程中：

应考虑恢复：


- 当前文档状态
- 当前选择状态
- 当前工具状态


避免影响后续任务。



---

# 八、日志与报告


Adobe生产脚本建议记录：


- 开始时间
- 结束时间
- 软件名称
- 文件数量
- 成功数量
- 失败数量
- 错误信息



报告用于：


- 问题追踪
- 生产检查
- 流程优化



---

# 九、Codex协作规则


Codex生成或修改Adobe脚本时：


必须：


1. 理解软件职责

2. 遵守对应专项文档

3. 保持已有生产逻辑

4. 说明修改范围

5. 保持兼容性



禁止：


未经确认：

- 更换自动化方式
- 大规模重构
- 改变生产流程
- 删除关键步骤
