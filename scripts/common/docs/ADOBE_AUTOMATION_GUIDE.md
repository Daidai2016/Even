# 八、Codex + Adobe 自动化执行流程

本节完善现有软件协作指南，不创建第二套脚本库。仓库 `AGENTS.md`、`CODING_RULES.md` 和软件局部 `AGENTS.md` 仍分别负责操作、代码与制作硬约束。

## 8.1 分清能力与执行状态

| 路线 | 何时使用 | 完成依据 |
| --- | --- | --- |
| 已有 JSX/Action | 固定、可重复且已有稳定入口的任务 | 目标 Adobe 中实际执行并检查代表性输出 |
| 当前可调用的 MCP/连接器 | 接口确实支持本次对象与操作 | 工具结果及目标文档内容复核；不按工具名称推断能力 |
| 可用的界面自动化 | 软件功能没有可靠专用接口，且能够观察页面 | 操作前后界面及实际文件检查；中文菜单名称以当前版本为准 |
| 新脚本/操作方案 | 尚无可执行接口或需开发稳定处理方法 | 只声明脚本/方案已完成，等待或执行真机验证 |

Adobe 云端图像服务或 Express 能力不自动等于控制本机 Photoshop/Illustrator。Illustrator MCP 已配置、端口监听、能列文档、能完成操作分别是不同证据；处理前核对真实目标文档，不改无关打开文件。

## 8.2 最小生产任务单

沿用工作台六项交接：目标、素材位置、锁定条件、已确认方案、输出规格、待办；只在生产需要时补充：

- 输入：源文件与版本、数量、目标文档/画板/图层，字体及链接资源是否齐全。
- 参数：物理尺寸和单位、像素、PPI、缩放比、色彩模式/位深/ICC、透明度、出血、安全区、格式和命名。
- 执行：选用哪个现有脚本及版本、是否需新版本、允许批处理范围、输出位置与失败处理。
- 验收：要求可编辑到什么层级、抽查哪些样本、哪些错误阻断交付。

不强制所有任务填写印刷或动态参数。纯矢量排版不套用位图 PPI 逻辑；1:10 大画面流程只用于已确认的制作方式。

## 8.3 从小样到批量

1. **读取**：检查适用规则、原脚本和目标素材；修改代码前检查本地 Git 状态，不执行无关同步。
2. **确认能力**：检测目标软件和当前工具支持；需要文档时核对文件名、路径、画板/图层。只做本地生产检查时，不顺手运行含 GitHub 网络检查或日志清理的全套环境脚本。
3. **保护原件**：优先副本和另存版本；保持稳定脚本。不能把当前打开文件视为用户允许覆盖的对象。
4. **代表性小样**：在已授权副本上覆盖正常输入与最可能失败的输入，例如缺字体/链接、特殊尺寸、中文路径或已有同名输出；只测试本任务实际存在的风险。
5. **核验后执行批量**：小样通过后沿用相同参数，按已授权数量执行。核对成功/失败/跳过列表，避免重跑覆盖已确认文件。
6. **处理异常**：普通单文件失败按既定策略隔离并记录；颜色、尺寸或保存策略整体错误时停止后续批次，保留可恢复现场。没有既定容错策略时不要擅自跳过关键错误。
7. **导出并重开**：核对实际源文件与导出；文件存在或返回成功不足以证明结果正确。
8. **交付**：面向操作者报告结果、异常与耗时；面向客户/供应商只写文件用途、规格和使用注意事项，不附调试信息。

## 8.4 软件验收重点

| 软件 | 重点检查 |
| --- | --- |
| Photoshop | 图层/智能对象/蒙版可编辑；边缘与透明度；像素和物理尺寸；是否重采样；模式、位深、ICC；导出压缩与命名 |
| Illustrator | 画板/单位/比例；可编辑路径与文字；中文排印、链接资源、描边/叠印/透明度、出血和裁切；未授权不转曲或栅格化 |
| InDesign | 样式、页码、溢流文字、缺字体/链接、跨页与出血、打包资源和 PDF 页面结果 |
| After Effects | 分层母版、锚点、时间轴、时长/帧率、运动与静态硬锁、首尾帧/循环、音轨、编码及逐帧异常 |
| Acrobat | 页数/页框/尺寸、字体、图像分辨率、透明度/叠印、色彩与印前目标；所需 PDF 标准由项目确定 |

屏幕交付与印刷交付分别确认色彩目标，不把 sRGB 或 CMYK 当成所有项目的固定默认。软件显示正常不替代导出后检查。
