# 单画面 V22：成功输出后关闭输入文档

使用入口：Photoshop“文件 > 脚本 > 浏览”，运行 `scripts/photoshop/jsx/large_format_single_file_process_v22.jsx`。原始 V21 保持不变。

图像与报告均成功保存后，使用 `SaveOptions.DONOTSAVECHANGES` 关闭本次输入文档，不弹出保存修改确认，也不将修改写回输入文件。运行前已有的未保存修改同样不会写回输入文件；输出仍按运行时文档内容生成。

取消操作、输出检查失败、图像保存失败或报告写入失败时，不自动关闭输入文档。若输出成功但关闭失败，明确提示输出已经保存，并提示手动关闭且选择“不保存”。其他打开的文档不受影响。

JPG/TIFF 格式跟随、JPG 品质 12 与基线标准、TIFF 单图层/LZW/透明保留，以及尺寸、像素、色彩和报告规则沿用 V21，详见 [格式与保存规格](output_formats_v21_v30.md)。多画面 V30 本次未修改。

原生回归入口：`scripts/photoshop/examples/test_single_close_v22.jsx`。测试仅操作自行创建的文档，覆盖 JPG/TIFF 成功关闭、报告失败保留窗口、取消保留窗口，以及其他文档保护；临时材料放在 `work/single_close_v22_<时间戳>/`，不属于生产交付或 Git 提交内容。

2026-11-04，在 Photoshop 27.11.0 中上述四种场景均验证通过：成功时输入窗口关闭，失败或取消时保持打开；输入文件在执行前后逐字节一致，重新打开仍为原始 300 ppi、原始图层数，运行前添加的未保存图层没有写回。其他测试文档保持打开。JPG/TIFF 输出均可重新打开，维持 30 ppi 和单图层。关闭本身发生异常的分支及其他 Photoshop 版本本次未实测。
