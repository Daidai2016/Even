# 七、图像尺寸与分辨率处理


Photoshop处理图像时：

必须区分：


- 物理尺寸
- 像素尺寸
- 分辨率属性



其中：


PPI：

表示图像分辨率属性。



DPI：

表示制作输出要求。



修改图像尺寸时：

必须明确修改目标。


需要根据实际需求判断：


- 是否保持像素数量不变
- 是否改变物理尺寸
- 是否调整分辨率属性


未经确认：

不得改变图像规模。
