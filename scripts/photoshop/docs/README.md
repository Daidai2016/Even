# 二、Photoshop自动化定位


Photoshop是主要的：

位图图像创作与处理平台。


自动化主要服务于：


- 数字图像创作
- 照片修饰
- 图像合成
- 图像修改
- 图像调整
- 特效制作
- AIGC素材处理
- 批量生产
- 印刷输出

# 三、Photoshop主要应用方向


## 1. 图像创作自动化


用于：


- 图像合成
- 创意效果制作
- 素材组合
- 风格处理
- 图像优化



主要对象：


- 图层
- 蒙版
- 通道
- 智能对象
- 调整图层



---

## 2. 照片修饰自动化


用于：


- 批量照片处理
- 色彩调整
- 影调优化
- 图片修复
- 商业摄影后期



---

## 3. 图像调整自动化


用于：


- 尺寸调整
- 分辨率处理
- 色彩管理
- 文件转换


注意：


涉及尺寸和分辨率时：

必须明确生产目标。


例如：

保持像素规模不变，仅修改PPI信息。


不得未经确认改变：

- 像素宽度
- 像素高度
- 图像内容



---

## 4. 特效与合成自动化


用于：


- 图层合成
- 效果制作
- 风格化处理
- 自动应用处理流程

# 五、印刷制作规则


Photoshop主要负责：

- 位图处理
- 图像调整
- TIFF输出
- 分辨率管理


涉及PPI处理时：


必须明确：

修改物理尺寸

或者

保持像素规模，仅修改PPI。


两者不能混淆。
