# 多图系列一致性反推

适用于用户提供多张同系列图片（同一角色、同一潮玩系列、同一海报风格），想反推"公共风格 / 统一设定"以生成同系列新图。

## 拆解步骤

1. 逐一读取每张图片，记录主体、风格、配色、材质、光线、构图。
2. 找出**公共元素**：所有图中一致的特征——角色五官与体型、配色体系、材质工艺、标志符号、背景与打光。
3. 找出**变化元素**：姿态、表情、场景、道具、视角（这些不写死，作为可替换项）。
4. 输出：核心设定 Prompt（固定项）+ 变化项占位说明，让用户换姿态/场景即可得到同风格新图。

## Prompt 模板

```
反推这一组图片的共同风格设定和 AI 绘图提示词。

分析：
1. 公共角色 / 主体特征（五官、体型、服饰）
2. 统一风格（画风、配色体系、材质）
3. 固定场景元素与打光
4. 每张图的变化点（姿态 / 表情 / 道具 / 视角）

输出：核心 Prompt（可直接用于生成同系列新图）＋ 变化项说明。
```
