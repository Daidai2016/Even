# 反推 Prompt 优化与验证经验

沉淀自验证闭环（按反推 Prompt 重新生成、与原图对比）的实际经验。输出反推 Prompt 前及验证迭代时使用。

## 核心结论

- 反推 Prompt 对**风格、色彩、构图、氛围**四维的还原度高，主要失分点在**文字层**：画面文案越多，模型渲染时越容易自行简化、改写甚至编造。
- 因此反推 Prompt 的文字策略优先于画面描述细节：少给模型文字，多给结构约束。

## 文字纪律

1. **控制文字组数**：只保留核心 3–4 组文案——超大主体字（如年份、主数字）、中文主标题、最关键的一句英文、日期/时间。次要文字（小号副标题、品牌名、装饰性英文）从 Prompt 中移除，或标注为"画面装饰小字、可不渲染"。
2. **事实信息原样处理**：日期、地点、价格等事实类文字，要么原样写出并加约束，要么完全不写（宁缺毋假），禁止让模型自由发挥。
3. **加强约束句**：在文字段落末尾写明"以上文字严格按引号内容原样渲染，不得增删、改写、补全"。
4. **明确层级**：用字号、位置、颜色绑定每组合义（如"超大号""中号""底部小字"），模型会优先保证大字准确。

## 结构纪律

1. **文字收进明确分区**：所有文字集中在描述清晰的分区（如左段），过渡区只写渐变、不安排文字，避免文字位置漂移。
2. **关键元素给明确位置与占比**：如"最右端 10% 宽度为锁屏风格块"，避免模型省略或位移。
3. **可舍弃元素显式标注**：原图中的装饰性收尾（如锁屏时间区、尾部的极简渐变块）如不影响风格验证，可明示省略。

## 验证对比方法

- 按反推 Prompt 用文生图重画（不要用原图作参考，否则失去验证意义）。
- 对比维度优先级：风格 > 色彩 > 构图 > 氛围 > 主体元素 > 文字。
- 文字逐字核对；出现模型自创内容（如编造日期地点）时，说明是 Prompt 文字过载或约束不足，按上文纪律收紧。
- 若需 1:1 复刻原图细节，改走图生图（原图作参考）更可靠；文生图验证的价值在于检验反推四维的准确性。
