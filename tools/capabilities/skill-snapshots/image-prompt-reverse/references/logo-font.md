# 字体 / Logo 设计类

适用于品牌视觉、字体海报、标志设计。

## 字体拆解四维度

| 维度 | 观察要点 |
|---|---|
| 字形特征 | 衬线 / 无衬线、圆角 / 锐角、粗细 |
| 质感效果 | 金属 / 玻璃 / 霓虹 / 浮雕 / 磨砂 |
| 排版方式 | 居中 / 倾斜 / 环绕 / 打散重组 |
| 配色方案 | 渐变 / 纯色 / 撞色 / 黑白金 |
| 文字内容 | 图中可见文字逐字识别，Prompt 中用引号精确标注（标题、品牌名、slogan） |

文字提取：含文字的图必须逐字识别图中文字内容，Prompt 中写死（如海报标题“夏日清凉节”）；识别不清时标注“推断”。

## Prompt 模板

输出给用户的 Prompt 按以下结构组织：

```
反推这个 Logo / 字体设计的完整提示词。

分析：
1. 字体风格（现代 / 复古 / 手写 / 像素）
2. 立体效果（浮雕 / 投影 / 发光 / 描边）
3. 材质质感（金属光泽 / 磨砂 / 玻璃折射）
4. 配色与背景关系

输出完整 Prompt。
```
