# 插画 / 二次元类

适用于扁平插画、治愈系、板绘、概念艺术。

## 插画拆解四层面

| 层面 | 观察要点 |
|---|---|
| 画风流派 | 扁平 / 厚涂 / 赛璐璐 / 水彩 / 线稿 |
| 笔触特征 | 粗线条 / 细腻 / 纹理 / 无描边 |
| 色彩逻辑 | 莫兰迪 / 高饱和 / 渐变 / 限定色 |
| 叙事元素 | 角色 / 道具 / 场景 / 故事感 |

## Prompt 模板

输出给用户的 Prompt 按以下结构组织，需附带风格关键词：

```
反推这张插画的绘画风格和 AI 绘图提示词。

分析：
1. 画风（手绘 / 板绘 / AI 风 / 混合）
2. 线条特征（有无描边、粗细）
3. 上色方式（平涂 / 厚涂 / 渐变）
4. 配色方案与氛围
5. 参考画师风格

输出完整 Prompt＋风格关键词。
```
