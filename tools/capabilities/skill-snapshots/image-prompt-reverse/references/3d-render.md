# 3D 渲染类

适用于写实渲染、卡通渲染、风格化 3D、产品渲染、场景渲染。

## 3D 渲染拆解五维度

| 维度 | 观察要点 |
|---|---|
| 渲染风格 | 写实渲染 / 卡通渲染（Toon）/ 风格化 / 低多边形 / 白模线稿 |
| 材质质感 | 金属 / 塑料 / 玻璃 / 布料 / 次表面散射（SSS）/ 磨砂 |
| 光照环境 | HDRI 环境光 / 三点布光 / 体积光 / 全局光照 / 边缘光 |
| 镜头与构图 | 广角 / 长焦 / 特写 / 微距 / 透视角度 |
| 渲染后处理 | 景深 / 辉光 / 反射 / 焦散 / 颗粒感 |

## Prompt 模板

输出给用户的 Prompt 按以下结构组织：

```
反推这张 3D 渲染图的 AI 绘图提示词。

分析：
1. 渲染风格（写实 / 卡通 / 风格化 / 低多边形）
2. 材质质感（金属 / 玻璃 / 塑料 / 布艺 / SSS 次表面散射）
3. 光照与渲染环境（HDRI / 三点布光 / 体积光 / 全局光照）
4. 镜头与场景
5. 后处理（景深 / 辉光 / 焦散 / 颗粒）

输出完整 Prompt。
```
