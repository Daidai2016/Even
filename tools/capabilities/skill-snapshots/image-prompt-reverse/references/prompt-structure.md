# Prompt 组织逻辑（输出结构模板）

反推输出的最终 Prompt 统一按以下 8 段固定顺序组织，保证画面完整、文字可控、无多余元素。各场景参考文件（general / logo-font / landscape 等）提供"拆解维度"，本文件规定"最终输出的 Prompt 长什么样"。

## 书写原则

- **尽可能采用自然语言书写**：8 段各写成连贯、通顺的完整句子，像向人描述画面一样叙述，而不是用逗号堆砌关键词标签（如"深蓝、渐变、扁平、粗体"式罗列）。
- 关键词（风格词、材质词、负面词）可以出现在自然语句中，但必须融入句子表达，如"整体采用现代简约的扁平矢量插画风格，以深蓝色为主色调"，而非"风格:扁平矢量，色彩:深蓝"。
- 自然语言 + 结构化分段兼顾：段落有清晰顺序（8 段），段落内部是通顺描述，方便模型理解与渲染。

## 固定结构（按此顺序成段）

1. **最终用途**：一句话说明图片用途（如活动主视觉超宽横幅、产品宣传海报、社媒封面），奠定整体基调。
2. **主体**：画面核心内容——谁 / 什么在画面中、在做什么、姿态与状态。
3. **构图**：画幅方向、分区方式、主体位置、阅读顺序（左右分栏 / 居中 / 三分法 / 对称等）。
4. **风格**：画风流派与视觉风格（扁平矢量 / 写实摄影 / 3D 渲染 / 插画等）+ 风格关键词。
5. **光线**：光源方向、软硬、色温、光效（逆光 / 侧光 / 渐变光晕 / 体积光等）。
6. **材质**：质感与纹理（金属 / 玻璃 / 磨砂 / 布料 / 颗粒 / 平滑渐变等）。
7. **文字**：全部可见文字，按下方文字规则逐组描述。
8. **不能出现什么**：负面约束（多余文字、logo、水印、模糊、变形等）。

## 文字规则（第 7 段内）

- 所有文字内容必须写在双引号内：中文用中文引号“”，英文用英文引号 ""。
- 每个文字组必须包含四要素：**内容**（引号内原文）、**位置**（左上角 / 底部居中 / 中段等）、**字体风格**（无衬线粗体 / 衬线体 / 手写体 / 数字体）、**视觉效果**（白字、描边、渐变、发光、字距拉开等）。
- 文字段末尾必须明确要求：不要生成多余的文字、logo、水印或其它图形元素。

## 负面约束（第 8 段）

- 通用负面：低分辨率、模糊、手指畸形、变形、水印、多余文字、乱码、多余 logo。
- 按原图实际缺点增删：画面干净则精简；画面有可见瑕疵则补充对应项。

## 结构示例（示意）

> 一张品牌新品发布的活动主视觉超宽横幅。主体为黑色剪影人物奔跑握拳立于几何平台之上。构图左右分栏：左约六成宽度为文字排版区，右约四成为扁平插画区。风格为现代简约商务扁平矢量插画，深蓝主色。光线为柔和渐变光晕，暖黄圆形光晕叠加于插画区。材质为平滑渐变、无纹理。文字：左上角中文“艺术设计智造”白色小字无衬线；中部超大号数字“2023”青蓝与白色双层粗体；下方中文“暨第五届旅游服务业最佳城市颁奖盛典”白色无衬线粗体居中；底部黄色英文"SUMMIT"字距拉开。不要生成多余的文字、logo、水印或其它图形元素。负面：低分辨率、模糊、文字乱码、多余手指。
