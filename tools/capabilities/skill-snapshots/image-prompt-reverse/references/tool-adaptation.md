# 工具适配输出与负面提示词

反推出的 Prompt 按用户的目标工具选择输出形态；用户未指定时，默认输出自然语言版（豆包 / GPT 通用）并附负面提示词。

## 输出形态对照

| 目标工具 | 输出形态 |
|---|---|
| 豆包 / GPT 等对话式 | 自然语言完整描述，直接粘贴使用 |
| Midjourney | 英文描述 + 参数后缀：`--ar`（按原图宽高比推断）、`--style`、`--v`、`--s` 等 |
| Stable Diffusion / 本地 | 英文描述 + 负面提示词 + 参数（采样器、步数、CFG、分辨率）；分辨率按原图比例给 512 / 768 / 1024 基准 |
| 可灵 / 即梦 / 混元等 | 自然语言描述 + 建议画面比例（如 3:4、9:16） |

## 负面提示词

随输出附上，按原图实际缺点增删：画面干净则精简；画面有可见瑕疵则补充对应项。

- 英文通用版：`lowres, bad anatomy, bad hands, extra fingers, deformed, blurry, watermark, text artifacts, oversaturated`
- 中文通用版：低分辨率、手指畸形、多余手指、变形、模糊、水印、多余文字、过饱和

## 文字内容输出

含文字的图（Logo、海报、标题图）在 Prompt 中必须精确写出文字内容，并用引号标注，例如：海报标题“夏日清凉节”。识别不清时标注“推断”。
