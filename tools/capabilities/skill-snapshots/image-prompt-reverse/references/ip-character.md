# IP 角色与潮玩设计类

适用于潮玩、盲盒、手办、Q 版角色、艺术玩具、IP 角色设定。

## IP 角色拆解五维度

| 维度 | 观察要点 |
|---|---|
| 角色造型 | 头身比（Q 版 / 正常 / 写实）、五官特征、姿态、服饰道具 |
| 风格流派 | 潮玩 / 盲盒 / 手办 / Q 版 / 艺术玩具 / 治愈系 |
| 材质工艺 | PVC / 树脂 / 毛绒 / 植绒 / 哑光磨砂 / 透明件 |
| 配色方案 | 限定色 / 渐变 / 撞色 / 荧光 / 莫兰迪 |
| 系列统一元素 | 标志性符号、家族化配色、统一背景与打光 |

## Prompt 模板

输出给用户的 Prompt 按以下结构组织，需附带风格关键词：

```
反推这个 IP 角色 / 潮玩设计的 AI 绘图提示词。

分析：
1. 角色造型（头身比、五官、姿态、服饰）
2. 风格流派（潮玩 / 盲盒 / Q 版 / 手办）
3. 材质工艺（PVC / 树脂 / 磨砂 / 毛绒）
4. 配色方案
5. 系列统一元素（标志符号、家族化风格）

输出完整 Prompt＋风格关键词。
```
