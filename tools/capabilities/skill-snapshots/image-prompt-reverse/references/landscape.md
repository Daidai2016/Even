# 风景 / 场景类

适用于自然风景、城市夜景、奇幻场景。

## 风景图拆解五层次

| 层次 | 观察要点 |
|---|---|
| 前景元素 | 花草 / 岩石 / 人物 / 建筑 |
| 中景主体 | 山脉 / 湖泊 / 街道 / 森林 |
| 远景背景 | 天空 / 云层 / 光线 / 雾气 |
| 时间光线 | 黄金时段 / 蓝调时刻 / 正午 / 夜晚 |
| 氛围营造 | 宁静 / 壮阔 / 神秘 / 梦幻 |

## Prompt 模板

输出给用户的 Prompt 按以下结构组织：

```
反推这张风景图的 AI 绘图提示词。

逐层分析：
1. 场景主体与季节
2. 时间段（日出 / 黄昏 / 夜晚）
3. 天气与光线条件
4. 色调倾向（暖调 / 冷调 / 日系）
5. 镜头感（广角 / 长焦 / 航拍 / 鱼眼）

输出完整 Prompt。
```
