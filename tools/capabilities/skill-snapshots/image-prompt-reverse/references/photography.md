# 摄影 / 人像类

适用于真人写真、产品摄影、街拍纪实。

## 摄影图拆解六参数

| 参数 | 观察要点 |
|---|---|
| 镜头焦段 | 35mm / 50mm / 85mm / 200mm |
| 光线类型 | 自然光 / 影棚灯 / 环形光 / 逆光 |
| 景深控制 | 大光圈虚化 / 全景深 / 中等 |
| 色调风格 | 胶片 / 日系 / 欧美 / 赛博朋克 |
| 构图手法 | 三分法 / 引导线 / 框架式 / 极简 |
| 后期处理 | 颗粒感 / 高对比 / 低饱和 / HDR |

电影感 / 影视质感的照片（剧照、电影感写真）还需额外观察：布光（伦勃朗光 / 蝴蝶光 / 剪影 / 霓虹夜光）、色彩分级（青橙 / 低饱和冷调 / 胶片暖调）、镜头语言（浅景深特写 / 长焦压缩 / 手持晃动感）。

## Prompt 模板

输出给用户的 Prompt 按以下结构组织，需包含摄影参数：

```
反推这张摄影作品的拍摄参数和 AI 提示词。

分析：
1. 相机与镜头（焦距、光圈）
2. 光线（方向、硬度、色温）
3. 后期风格（胶片 / 数码 / 复古）
4. 人物姿态与情绪

输出包含摄影参数的完整 Prompt。
```
