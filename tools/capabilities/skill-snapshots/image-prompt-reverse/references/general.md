# 通用图片反推（万能模板）

适用于所有类型图片；无法确定具体类别或混合类型时使用。

## 拆图七要素

| 要素 | 观察要点 |
|---|---|
| 主体内容 | 画面核心是什么（人物 / 物体 / 场景 / 抽象） |
| 风格判断 | 写实 / 插画 / 3D / 像素 |
| 色彩分析 | 冷暖色调、主色、对比度 |
| 光影方向 | 顺光 / 逆光 / 侧光 / 环境光 |
| 构图方式 | 对称 / 三分法 / 特写 / 俯视 |
| 质感细节 | 分辨率、材质、纹理 |
| 氛围情绪 | 治愈 / 赛博 / 复古 / 史诗 |

## Prompt 模板

输出给用户的 Prompt 按以下结构组织：

```
请详细反推这张图片的 AI 绘图提示词。

按以下维度逐一分析：
主体、风格、色彩、光影、构图、质感、氛围、分辨率。

输出完整 Prompt。
```
